# math_statistics_analysismath_statistics_analysis
Учебный проект по математической статистике: анализ распределений, расчёт выборочных характеристик и проверка статистических гипотез.

**Часть 1. Анализ статистических распределений**

Цель: исследовать выборки различных распределений, рассчитать выборочные характеристики и сравнить их с теоретическими значениями.

Распределения:
- Биномиальное (\(n = 19,\ p = 0{,}478\))
- Отрицательное биномиальное (\(r = 5,\ p = 0{,}967\))
- Показательное (\(\lambda = 0{,}967\))

Что сделано:
- Сгенерированы выборки объёмом \(N = 200\)
- Построены вариационные и статистические ряды, эмпирические функции распределения
- Рассчитаны выборочные среднее, дисперсия, среднее квадратическое отклонение, мода, медиана, коэффициенты асимметрии и эксцесса
- Построены полигоны относительных частот и гистограмма с теоретическими вероятностями и плотностью распределения
- Составлены таблицы сравнения выборочных характеристик с теоретическими значениями
- Для показательного распределения рассчитана дисперсия с поправкой Шеппарда

**Часть 2. Проверка статистических гипотез**

Цель: проверить соответствие выборок заданным теоретическим распределениям с использованием статистических критериев.

Что сделано:
- Критерий согласия Пирсона \(\chi^2\): проверена гипотеза о нормальном распределении
  - Построена гистограмма относительных частот с наложенной плотностью нормального распределения
  - Рассчитаны оценки математического ожидания и дисперсии
  - Получено \(\chi^2 = 6{,}59149\) при критическом значении \(12{,}37462\) и уровне значимости \(\alpha = 0{,}03\) → нулевая гипотеза не отвергается
- Критерий Колмогорова: проверена гипотеза о показательном распределении с параметром \(\lambda = 1{,}767\)
  - Построена эмпирическая функция распределения и выполнено её сравнение с теоретической
  - Рассчитана статистика \(D_N\sqrt{N}\) и проведено сравнение с критическим значением при заданном уровне значимости

**Результат:** выполнен статистический анализ трёх распределений, исследованы выборочные характеристики и их отклонения от теоретических значений, проведена проверка статистических гипотез с интерпретацией результатов.

**Инструменты:** генерация псевдослучайных выборок, статистические расчёты, построение графиков и табличное представление результатов.
